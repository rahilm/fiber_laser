# Report

Production records and logs. *This guide is a starter; the Report workspace of the Wave 3
interface extends it.*

## Work reports

mlaser records every job: start and end time, cutting time, cut length, pierces and the drawing.
**System Analysis → Work Report** shows the new records, **Work Report [All]** all of them, with
filters, totals and printing.

## Logs

The log panel at the bottom shows the session. **System Analysis → Log folder** lists the log
files (`mlaser.log`, the safety `audit.log` and `crash.log` in the data folder).

## Device report

**System Analysis → Device report** collects the card, follower and laser information for a
service request.
